# SORITECH INNOV BUSINESS — Site officiel

Site vitrine statique de SORITECH INNOV BUSINESS (SIB).

**Slogan :** INNOVER • DÉVELOPPER • CONNECTER

## Publication GitHub Pages
Le workflow `.github/workflows/pages.yml` publie automatiquement le site à chaque push sur `main`.

1. Ouvrir **Settings → Pages** dans ce dépôt.
2. Dans **Build and deployment → Source**, sélectionner **GitHub Actions**.
3. Attendre l'exécution du workflow **Deploy SIB website to GitHub Pages** dans l'onglet Actions.
4. L'URL GitHub Pages sera affichée dans le déploiement.

## Domaine personnalisé
Après avoir acheté et contrôlé `soritechinnov.com`, ajouter ce domaine dans **Settings → Pages → Custom domain**, puis configurer les enregistrements DNS indiqués par GitHub. Le domaine n'est pas considéré comme connecté tant que la configuration DNS et HTTPS n'est pas validée.

## Contact
Les coordonnées affichées sont celles fournies pour l'entreprise. Le formulaire ouvre WhatsApp avec un message prérempli ; aucun service e-mail/backend n'est configuré.
